# M1 整改方案（先量后治）

> 2026-10-13 ｜ 针对《M1排期与交付公约》与项目实况的落差（详见 `M1公约对比分析_20261013.md`）

---

## 0. 先分叉：优化目标决定方案

| 目标 | 最优动作 | 代价 | 现状 |
|---|---|---|---|
| **A** 本地 25 局分 | 继续补表（照搬 tu93 离线搜索法） | 官方隐藏集**不动** | 49.20（已验证补一局 +3.4） |
| **B** 官方隐藏集 | **必须闭卷通用**（公约原意） | 慢、短期本地分大跌 | 0.04 |
| **C** 验证 M1 方法论 | 建闭卷基线、出对照数字 | 只是度量、不涨分 | 无基线 |

**三者互斥**：A 与 B 的最优动作方向相反；C 是 B 的前置。
**本方案推荐：先做 C（零风险），再用 C 的结果决定 B 怎么走。** A 只在目标明确为 A 时才做，且不得写进对外成绩口径。

---

## 1. 三步路线

### ① 度量 · 闭卷基线（零风险，先做）

- **做法**：给 agent 加一个环境开关（如 `LINGJING_CLOSED_BOOK=1`），**只关闭决策链的 ② 内联解法层与 ③ EngineSolver 白名单**，保留 ④ R3 IDDFS + Hybrid 热图与 ⑤ CEAX 兜底，末端 AOP 不变。默认关闭 → **主链零改动、零回归**。
- **跑两次**：AR25 L1–L3（M1 原始目标）；全 25 局（得"闭卷地板"）。
- **产物**：三列对照表 `canned / closed-book / official`。
- **验收**：AR25 前三关在闭卷下要么通关，要么逐关记录失败点（超时 / 步数 / 状态）。

### ② 扶正 · R3 主链升为默认

- **做法**：决策链默认顺序改为 **R2 感知 → R3 pathify**；② 内联表改为 `--allow-canned` 显式开启的调试旁路。R3 的 `search/`、`simulator/`、`r3_kernel.py` 已存在，只是当前没被主链调用。
- **验收**：25 局不开罐头仍达到可接受地板（先设 20 分口径），且 `pytest` 全绿。

### ③ 治理 · 门禁反向 + 口径对齐

- **做法**：CI 的 `route-gate` 由"路线三遍复现"改为"**闭卷三关三遍复现**"；新增 grep 门禁拦截 `set_level(` / `._game` / 新增硬编码计划表。
- **口径**：对外固定两列「本地（含罐头）/ 官方」，未达标局显式标注。
- **验收**：故意塞一段 `set_level` 代码 → CI 必须红。

### 并行线 · 确定性化

把墙钟预算（`t_limit` / `time_budget=300` / IDDFS 20s）换成**节点预算**，消掉 run-to-run 抖动。
理由：主跑分里 cn04 掉关就是撞上并行提交的 CPU 争抢（`r3-none (no path within budget)`）；不解决它，A/B 结论都不可信。

## 2. 可量化目标

| 指标 | 现状 | 目标 |
|---|---|---|
| 闭卷 AR25 L1–L3 | 无基线 | 有明确数字（哪怕 0） |
| 闭卷 全 25 局 | 未测 | ≥ 20 |
| 官方 Kaggle | 0.04 | 提交一次，结果**可解释**（涨或平都能说清） |
| run-to-run 抖动 | 存在 | 同配置两次**完全一致** |

---

## 3. 风险与规避

1. **闭卷分可能极低（接近 0）** —— 这是**信息**，不是失败；M1 当初要的就是这个数。规避：把它写成基线而非成绩。
2. **R3 主链可能不具备端到端能力** —— 那正是公约里 R2/R3 该干的活，是要修的根因。规避：Step ① 先量出缺口在哪几关。
3. **改主链引入回归** —— 规避：Step ①② 全部用开关隔离，前后 A/B 对比（本次已有 `state/_ab_determinism.py` 可复用）。
4. **并行会话继续提交主链** —— 规避：动主链前先确认无并行改动（本次 410fef4 已踩过一次）。

---

## 4. 暂缓 / 不做

- **继续补表**（lf52 / re86 / s5i5 / ka59 / dc22 / m0r0 / sp80）：仅在目标确认为 **A** 时做；且不得进对外口径。
- **追优化 `t_limit` 参数**：属噪声范围内的调参，被并行线的确定性化取代。

---

## 5. 一句话

**先花半天量出"去掉罐头还剩多少"，再决定要不要把主链换掉。** 现在的 49.20 是个无法解释的数；先要一个能解释的数。
