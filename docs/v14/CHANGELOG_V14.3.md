# 灵境引擎 V14.3 变更记录 —— 「场方程补全」

> 版本主题：**从纯扩散 `D∇²φ + J` 升级为 v13.2 完整场方程 `dΦ/dt = D∇²Φ − γΦ − λΦ(Φ²−Φ₀²) + J`**。
> 不破坏 V14.2 契约底座（默认 γ=0, λ=0 向后兼容），落地隐式求解器（从 TODO 变真）。

---

## 一、动机：V14.2 底座已稳，但场方程是"缺腿"的

V14.2 把"写场契约"硬化后，守恒恒等式 `ΔΣφ = dt·ΣJ` 在机器精度上成立。但对照 v13.2 §7.1，当前场方程只有两项：

```
V14.2:  dφ/dt = D·∇²φ + J              （扩散 + 源项）
v13.2:  dΦ/dt = c²∇²Φ − γΦ − λΦ(Φ²−Φ₀²) + J   （波动 + 耗散 + 自作用 + 源项）
```

缺的两项不是可选项：
- **耗散 −γΦ**：信息场不可能无限存续，熵增是物理真实；没有它，场会永远震荡/扩散不衰减。
- **自相互作用 −λΦ(Φ²−Φ₀²)**：双势阱项，让信息密度有"紧束缚态"（孤子/斑图），否则场里只有线性扩散波，不会涌现结构。

同时 V14.2 遗留 TODO：隐式求解器 `_evolve_implicit` 实际 fallback 到显式子步，注释标着 `TODO(M1)`。V14.3 一起落地。

## 二、核心改动

### 2.1 `core/field.py` — FieldConfig 参数化

```python
@dataclass
class FieldConfig:
    shape: tuple[int, int, int]
    h: float = 1.0
    D: float = 1.0
    # V14.3 新增（默认 0 = 关闭，向后兼容）
    gamma: float = 0.0      # 耗散系数 γ
    lam: float = 0.0        # 自耦合 λ
    phi0: float = 0.0       # 真空基线 Φ₀
    scheme: Scheme = "implicit"
```

**设计决策**：默认值全 0，意味着现有所有场景（Evacuation 等）不传新参数时，行为与 V14.2 逐位一致。新物理项 opt-in。

### 2.2 `core/field.py` — 显式演化补两项

```python
# V14.2:
lap = self._laplacian_volume(phi)
phi += dt_sub * D * lap

# V14.3:
lap = self._laplacian_volume(phi)
dissipation = -gamma * phi                          # −γΦ
self_interact = -lam * phi * (phi² - phi0²)       # −λΦ(Φ²−Φ₀²)
phi += dt_sub * (D * lap + dissipation + self_interact)
```

### 2.3 `core/field.py` — 隐式求解器落地（M1 TODO 关闭）

半隐式后向欧拉：线性项隐式，非线性自作用项显式评估在右端。

```
(I − dt·D·L + dt·γ·I) φ_new = φ + dt·J − dt·λ·φ·(φ²−Φ₀²)
```

- Neumann 零通量边界在 CSR 稀疏矩阵层面复现（`_build_neumann_laplacian_csr`），与显式路径逐点一致
- scipy `spsolve` 求解，lazy 缓存 L 矩阵
- γ=0, λ=0 时退化为标准后向欧拉 `(I − dt·D·L) φ_new = φ + dt·J`

### 2.4 守恒恒等式修正

| 情形 | V14.2 | V14.3 |
|---|---|---|
| γ=0 | ΔΣφ = dt·ΣJ | ΔΣφ = dt·ΣJ（不变） |
| γ>0 | 不成立（无此物理） | **ΔΣφ = dt·(ΣJ − γ·Σφ)** |

新增 `field.cumulative_dissipation` 属性，追踪累计被耗散项抽走的 Σφ。

## 五、诚实边界

1. **半隐式而非全隐式**：非线性项 λΦ(Φ²−Φ₀²) 用显式评估在右端（Picard 步），不是 Newton 迭代。λ 很大时可能需要迭代修正；当前 λ 默认 0，实际场景先小步长验证。
2. **Neumann 边界在 CSR 里逐节点构造**：N³=4096 节点时可接受；N≥128（200 万节点）时构造矩阵会慢，届时需要向量化构造或 CUDA。
3. **耗散项追踪用 φ_new 近似**：后向欧拉下 ΔΣφ = dt·(ΣJ − γ·Σφ_new)，与连续理论的 −γ·Σφ̄（平均值）有 O(dt) 差。C13 用 rel_err < 1e-8 验收，数值上足够。
4. **波动语义未引入**：当前 D∇²φ 仍是扩散方程（一阶时间），不是波动方程（二阶时间 ∂²φ/∂t² = c²∇²φ）。v13.2 的 c²∇²Φ 在本实现里记为 D，但物理上是扩散近似。真正的波动方程（二阶时间）留待 V14.4 几何层一起考虑。
5. **8 个 torch 依赖测试仍未跑**（AOP 神经网络相关，不在物理引擎范围）。
