## 0. 一句话范式

> **不预先在三维容器里堆体素，只把信息编译在二维全息膜（泡壁）上；场方程每 tick 自演化出下一帧，Agent 靠版本号读同一份事实，互不发消息。**

三大代际断层（替代关系）：

| 现有拼凑方案（O(L³)） | 灵境引擎（O(L²)） | 断层本质 |
|---|---|---|
| 体素/刚体碰撞 | 拓扑流形 + 统计熵流 | 不是优化，是复杂度下界从 L³ 降到 L² |
| 消息通信/锁/仲裁 | 版本号 + 统一求解的场演化 | 共识是场的数学性质，不是 Agent 间协议 |
| 全局物理时钟 `DeltaTime` | 锚点固有时 τ（纤维丛）+ 光锥采样帧 | 没有绝对时间，只有因果边界扫描速率 |

### 协议 6 的 R1–R5 规则（确定性共识的数学保证）

- **R1**：所有 Agent 在 tick N 开始时必须读 V_N 快照。
- **R2**：所有 tick N 内的决策都基于同一个 V_N。
- **R3**：所有 Action 统一提交到场演化层（不立即写场）。
- **R4**：tick N 结束时，场演化层用全部 Action 统一生成 V_{N+1}。
- **R5**：tick N+1 开始时所有 Agent 读 V_{N+1}。

> 关键：写入顺序无关（加法交换律 + 场方程确定性）。离线 Agent 重连后**只读一次最新 V_current** 即可追上，不需要补消息。

## 4. 关键公式

### 4.1 场演化（协议 7.1，3+1 维离散化）

```
Φ_{N+1}(x,t) = Φ_N(x,t) + dt · ℰ(Φ_N, J, ∇²Φ)
```

其中演化算子 ℰ 四项：

| 项 | 数学形式 | 物理含义 |
|---|---|---|
| 波动项 | `c² ∇²Φ` | 扰动以有限速度 c 传播（因果律，不超光速） |
| 耗散项 | `−γ Φ` | 能量耗散、熵增，扰动渐平 |
| 自相互作用 | `−λ Φ(Φ² − Φ₀²)` | 非线性，孤子/粒子凝聚态形成 |
| 源项 | `J(x,t)` | Agent / 物质注入，上行反馈 |

工程实现（PDF 给出的 NumPy 骨架）：

```python
def evolve_field(phi, dt, J):
    laplacian       = compute_laplacian(phi)          # c²∇²Φ
    dissipation     = -gamma * phi                    # -γΦ
    self_interact   = -lambd * phi * (phi**2 - phi0**2)
    source          = J
    dphi_dt = c**2 * laplacian + dissipation + self_interact + source
    return phi + dt * dphi_dt
```

守恒：总信息量 `∫σ dS = ∫ρ dV`，源项只重分配信息，不创造信息。

### 4.2 几何生成（协议 3）

```
g_μν = η_μν + (1/I_Pl) · ∂_μΦ · ∂_νΦᵀ + κ · (Φ² − Φ₀²) · η_μν
R = Ricci_scalar(g)
```

真空均匀 Φ（无梯度）→ 平坦时空（无物理事件）；Agent/物质扰动 → Φ 梯度 → 弯曲 → 影响其他 Agent 的测地线与泡壁交叠度 Ω_ij。

### 4.3 共识（协议 6）

```
J_total(x,t) = J_0(x,t) + Σ_{i=1..N} ΔJ_i(x,t)
Φ_{N+1}      = Φ_N + dt · ℰ(Φ_N, J_total)
V_{N+1}      = V_N + 1
```

### 4.4 面积律（协议 7.2）

清晰区是二维球面 `A = 4πR²`，不是三维体积 `V = 4/3 πR³`。

| 尺度 R | 体积渲染 O(R³) | 面积渲染 O(R²) | 节省倍数 |
|---|---|---|---|
| 10 | 1,000 | 100 | 10× |
| 100 | 1,000,000 | 10,000 | 100× |
| 1000 | 1,000,000,000 | 1,000,000 | 1000× |

## 8. 关键哲学锚点（迭代时不要丢的第一性原理）

- **信息本体论**：不引入"物质 vs 信息"二元，物质就是信息密度场 Φ 的孤子/驻波解；四力是同一信息网络在不同拓扑截面上的曲率。
- **观测即边界**：Agent 从未"进入"三维空间，它的一切认知都是泡壁二维边界信息的解码重建（类比视网膜）。
- **信息守恒**：完整信息已编译在全息膜上，演化用测地线降维，既不丢失也不创造信息；迷雾区不是"冻结/删除"，而是粗粒化为统计熵流。
- **自指闭环 = 面积律**：生命/智能是"自指拓扑泡"，索引是纤维丛（生物电信号），临界相变 C 值 = 拓扑容量每秒突触数。
- **LLM 只做决策**：LLM 不需要懂场方程，只读 PerceptionSnapshot、输出 Action；物理由场方程自动演化。
