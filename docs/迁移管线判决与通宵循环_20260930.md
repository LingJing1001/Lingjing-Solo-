# 迁移管线判决与通宵循环 —— 2026-09-30

本文记录 affordance 迁移管线的建设、四组判决实验的结论，以及 AutoResearch 式
通宵循环的落地。所有数字可由文中命令复现；判据与产物已登记
`state/skills/manifest.json`，实验流水在 `state/ledger.jsonl`。

## 一、管线（全部已入库）

```

state/affordance_grids.npz       2456 张唯一网格（grid_hash → 64×64）

overnight.py                     AutoResearch 循环（Selector→Trainer→Validator→Keeper）

```

标签基（关键设计）：`productive = {state_only, advance, win}` —— state_only
（屏幕不动、引擎状态变）由 `_get_hidden_state()` 兜住，根治热图 v1 的标签毒化；
screen 是负类（相机会/移动局像素几乎必变，含它则 99% 全正、失去判别力）。

## 三、通宵循环（AutoResearch 四件套）

- **账本** `transfer/ledger.py`：verdict/experiment 统一 schema；CEAX 运行时
  `CEAX_LEDGER=1` 每 verdict 落 `state/ceax_ledger/<game>.jsonl`（best-effort）。
- **manifest** `state/skills/manifest.json`：skill = {kind,path,version,gate,status}；
  status ∈ active/shadow/discarded；**discarded 不被 register 静默复活**（闸门语义）。
- **治理** `prune_click_targets`：CEAX_PRUNE=1 时每 100 verdict 退役死目标
  （trials≥6 且均值<floor 且从未推进；untried/progressed 永不退役）。
- **循环** `overnight.py`：Selector→Trainer→Validator→Keeper；keep 判据 =
  candidate 扩容 pooled > incumbent + 0.05 噪声地板；每迭代写账本一行。

循环冒烟全通（2-epoch 候选被正确判 discard）。两 flag（CEAX_LEDGER/CEAX_PRUNE）
默认关闭时 CEAX 行为逐位不变、签名/返回零改动。

## 四、评测扩容（Validator 的教训）

旧协议 5 局×1 入口帧×10 提案，噪声 ±0.15——**0.5 晋级线在该样本量下无判决力**
（本轮 v3 0.320 vs v5b 0.260 统计上分不开；两套 GT 连排序都不一致）。
扩容后：34 状态（×6），v3 pooled 0.194；亏损形态明确——r11l recall 0.83 而
precision 0.08（top-10 稀释）。**先扩评测，再谈模型**是热图线的硬前提。

## 五、修复的生产 bug

`planning/search/generic_shadow.py::generic_snapshot`：逐属性 deepcopy 使
`{sprite: n}` 这类 identity 键表与 sprite 列表断裂，restore 后引擎查表
`KeyError: Sprite`——vc33 实测，任何带 identity 键注册表的隐藏局 R3 静默失效。
修复 = 整字典单次 deepcopy（共享 memo）。

## 六、未决事项

1. bp35 L2：需专用候选生成（现有组件中心 + 16 击深度不够）。
2. 排序器搜索价值：仅 cn04 一局归因成立且跨重训不稳定；想救它先扩评测再重验。
3. 热图 0.5 晋级线：待更多迭代（overnight seeds）与更大评测池。
4. metadata `baseline_actions`（人类步数）不可回放，如需人类基线得另找来源。
