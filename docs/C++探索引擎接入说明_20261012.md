## 1. 目标

用 C++ 加强「数字世界未知环境」探索，而不是重写整个 Arcade：

| 仍归 Python | 下沉到 C++ |
|-------------|------------|
| `perform_action` / 游戏规则 | 状态哈希 `u64` |
| 校准计划播放 | `Visited` 去重 |
| CEAX / AOP 决策 | beam top-k |
| | 紧凑 BFS 路径调度 |

核心逻辑：**未知关靠搜索；搜索的数据结构越快，同样时间预算能扩更多节点。**

## 4. 接到 my_agent（下一步）

### 已接到正式 Agent（本轮完成）

`agent/my_agent.py`（已同步 `vendor/.../templates/my_agent.py`）：

| 函数 | C++ 用法 | 回退 |
|------|----------|------|
| `_bfs_search` | `CompactBFS` 管 queue/seen/path | 原 Python `deque`+`set` |
| `_iddfs_search` | `Visited` 精确去重（余弦软过滤仍保留） | 原 Python `seen` set |

日志指纹：`bfs-cpp on` / `iddfs-cpp-visited on` / `BUILD_TAG` 含 `+cpp-explore-bfs-iddfs`。  
DLL 缺失时自动回退，不影响计划关与 CEAX。

## 5. 与比赛叙事的对齐

- 「未知环境冲关」= 无先验计划时的搜索求解

- C++ 负责探索引擎的热路径，Python 负责环境与策略编排  

这是灵境战队把 C++ 能力接到 ARC-AGI-3 的第一刀：可测、可扩、不破坏现有 42.8 分计划路线。
