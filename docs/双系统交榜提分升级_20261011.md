## 1. 升级原则（相对旧提分路线）

| 项 | 旧路线 | 本升级 |
|----|--------|--------|
| 主分来源 | 确定性 plan + 回放 | **不变** |
| AOP | 不控盘 | **不变**（shadow only） |
| unknown | CEAX + 硬编码路径上的 IDDFS | 相对路径 + 感知 top-K + V14 保守剪枝 |
| 本地验收 | 常混用 200 步 | **统一 800 步** |
| 双系统叙事 | 未写入交榜 | 快提案 / 慢验证写进 Agent 接缝 |

**公式不变，接缝升级：**

```text
补全并验证确定性 plan（最大涨幅）
        ↓
感知剪枝强化 CEAX / hybrid-click（已知局再挖关）
        ↓
可解析环境根 + clone 搜索（unknown 破零）
        ↓
V14 / replay 作裁判（假路径 fail-closed）
        ↓
Kaggle Phase B（本地不回退后再交）
```

## 2. 双系统 ↔ 交榜映射

```text
观测 frame
  → 感知引擎（PerceptionEncoder ROI/对象中心 top-K）
       ├─ System 1：hybrid-click / CEAX 候选 / AOP shadow
       └─ 物理引擎：clone IDDFS/BFS + V14 无效边剪枝 + replay
            → System 2：已校准 plan 优先；搜索路径验证失败则清空回退 CEAX
```

| 组件 | 交榜用法 | 预期贡献 |
|------|----------|----------|
| 确定性 plan + 3× replay | System 2 主控 | 最大（ls20/ar25/已 WIN 局） |
| 感知 top-K 点击 | 收窄 ACTION6 | CEAX / unknown +1～2 关 |
| 相对环境根 + IDDFS | unknown 可本地复现 | 破 0 关 |
| V14 保守剪枝 + 路径失败清空 | 少假路径 | 稳分、不拖累 WIN |
| AOP shadow | 只记日志 | 0 直接分 |

## 3. 工程变更清单（第一波）

### P0 — 路径 fail-closed

- 移除 `C:/newtask-pi`、`F:/pro2` 硬编码
- 解析顺序：`LINGJING_ARC_ROOT` / `LINGJING_ENVIRONMENTS_DIR` → Starter `environment_files` → 仓库 `environment_files` → cwd
- `arc_adaptor`：从仓库根挂 `sys.path`，不再依赖本机盘符
- clone 搜索根目录不可用 → **跳过搜索、回退 CEAX**（不抛死 Phase B）

### P1 — 感知 top-K

- `PerceptionEncoder`：delta ROI / 对象中心 → ACTION6 候选（K≤8）
- 仅用于 hybrid-click 与 R3/IDDFS 点击扩展
- **不改写** `ROUTE_INLINE` 与已校准 `_XX_PLANS`
- 无感知结果时保持原 hybrid / 热图 / 非背景采样行为

### P2 — 物理裁判

- 在线记录「空效果」动作（grid 不变）→ 搜索时保守跳过高置信无效边
- V14 场梯度：点击候选按梯度排序，过长时丢弃底部低梯度点（有梯度才启用）
- R3 路径执行中动作非法 → 清空 `_r3_path` 回退 CEAX

### P3 — Plan 主分

| 游戏 | 状态 | 动作 |
|------|------|------|
| ls20 | 代码已含 L0–L6（7 关）全 plan | `--max-steps 800` 验 WIN |
| ar25 | 代码已含 L0–L7（8 关）全 plan | `--max-steps 800` 验 WIN |
| wa30 | L0–L2 硬编码 + 在线 `_wa30_make_plan` | 800 步挖 L3+ |
| sc25 / bp35 | 既有 plan | 补关 + 防漏进 CEAX |

## 4. 接口契约（最小接缝）

### 4.1 感知输出（System 1 提案）

```text
perc_clicks(grid, prev) -> list[(x, y)]   # 长度 ≤ 8
  来源优先级：对象中心(按面积) → delta 像素采样 → （可选）热图补充
```

### 4.2 物理/搜索（System 2）

```text
resolve_environments_dir() -> Path | None
iddfs/bfs：根为 None → return None（CEAX 接管）
prune：noop 计数 ≥ 阈值 或 低梯度点击（保守）
r3 执行失败 → clear path
```

### 4.3 禁止

- AOP `used_for_control=true`
- 感知/V14 改写已校准 INLINE plan
- 未 800 步回归就 Phase B 刷额度
