### 2.3 AOP 与打榜的关系

- **AOP 训练的是**：`(观测, 动作) → 是否生效 / 是否推进 / 动作类别`
- **不是**：`(观测) → 下一步该点什么`（策略模型）
- **当前打榜 Agent**：`integrations/ARC-AGI-3-Kaggle-Starter/agent/my_agent.py`  
  `BUILD_TAG = smart-router-v2+... +v14.2-transition`，`MAX_ACTIONS = 800`
