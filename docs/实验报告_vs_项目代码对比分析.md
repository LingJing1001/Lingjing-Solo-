## 一、实验报告核心发现

### ls20 游戏机制

ls20 是一款**离散网格导航 + 形状/颜色/旋转匹配**解谜游戏，核心规则：

| 要素 | 说明 |
|---|---|
| 玩家 | 5×5 像素块，每步沿四方向移动 5 像素（ACTION1–4） |
| 目标 | rjlbuycveu 标记的 5×5 区域：玩家块必须站到目标格，且形状索引、颜色索引、旋转角度与目标一致 |
| 旋转台 | rhsxkxzdjz — 每次踏入触发 +90° 旋转 |
| 调色台 | soyhouuebz — 每次踏入切换颜色 |
| 形状台 | ttfwljgohq — 切换形状模板 |
| 幽灵预览 | hoswmpiqkw — 不参与碰撞的预览格 |
| 步数限制 | 每关 StepCounter=42，无效移动扣步数，耗尽则 Game Over |
| 关卡数 | 7 关，通关全部子目标后进入下一关 |

### 全关卡机制

| 关卡 | 主题 | 匹配要求 | 修饰台 | 步数限制 |
|------|------|----------|--------|----------|
| Level 1 | 旋转教学 | StartRot=270°→GoalRot=0° | 旋转台 (19,30) | 42 步 |
| Level 2 | 远距旋转 | StartRot=0°→GoalRot=270° | 旋转台 (49,45) | 42 步 |
| Level 3 | 颜色+旋转 | StartColor=12, GoalRot=180° | 旋转台 (49,10) | 42 步 |
| Level 4 | 换形状 | StartShape=4, 需形状台 | 形状台 (fesygzfqui) | 42 步 |
| Level 5 | 调色 | GoalColor=8 | 旋转+调色台 | 42 步 |
| Level 6 | 双目标 | GoalColor/Rot 列表 | 旋转台 (34,40) | 42 步 |
| Level 7 | 迷雾 | Fog=True | 旋转台 (54,10) | 42 步 |

### 实验结果

- **平均完成关卡数：1.00 / 7**
- **Level 1 通过率：3/3（100%）**，平均 13–14 步通关（优于 baseline 22 步）
- **Level 2+ 全部失败**：原因是在 (29,40) 等处被**动态移动平台**（npxgalaybz）阻挡，静态 BFS 路径失效，步数耗尽

### 最严重问题

**planning/ls20_solver.py 不在 zip 包中**。
DGX 上的副本同样没有。解释了为什么"接入 Agent"但只能过 1/7 关卡。

### 实验结果归因

```
Level 1 通过 (13-14 步)
  ├─ BFS 路径规划：玩家 → 旋转台 → 目标 ✅
  ├─ 旋转角度匹配：StartRot 270° → 旋转台 → GoalRot 0° ✅
  └─ 无障碍动态平台 ✅

Level 2 失败 (步数耗尽)
  ├─ 动态移动平台 (29,40) 阻挡路线 ❌
  ├─ 静态 BFS 无法处理移动平台位置变化 ❌
  └─ StepCounter 42 步耗尽 → Game Over ❌
```
