## 3. Agent 侧能力（本分支增量）

相对旧 dpl 分支，本分支已有：

- `AOPController`（高置信可选接管，环境变量门控）
- `engine_solver` + probe cache / CEAX giveup150
- action mask、evaluate/qa/collect、shadow / scorecard reaper 工具链
- 声称 lp85 引擎解法路径（需本机环境验证）

### 3.1 回归：engine/AOP 抢占校准 plan

合并后全量 25@200 曾掉到 ~31.2，**sb26 WIN→0**（表现为 ACTION7 刷屏）。根因：

1. `EngineSolver` 在 `choose_action` 入口对任意局抢占，白名单含 plan 局  
2. AOP controller 在默认路径自动加载，末端改写破坏校准序列  

修复（`BUILD_TAG` `+plan-protect`）：

- `_PLAN_PROTECTED_GAMES`：ls20/ar25/ft09/tr87/vc33/sb26/r11l/cd82/tn36/sc25/bp35/wa30  
- `_ENGINE_SOLVER_GAMES` 收窄为 unknown-only（去掉 bp35/sc25/wa30 等）  
- AOP 仅 `_aop_mode()!="off"` 时加载；plan/INLINE 局跳过一切 AOP 改写  
- 尊重 `ENGINE_SOLVER=off`；环境目录优先 Starter `environment_files`

### 3.2 本机复测（AOP=off，`@800`）

校准 7 局 Aggregate：**100.0**。全量 25 日志：`data/full25_percr3cap_800.log`。

| 档 | 局 | 结果 |
|----|----|------|
| **WIN（10）** | ar25(8)、cd82(6)、ft09(6)、**lp85(8@79)**、ls20(7)、r11l(6)、sb26(8)、tn36(7)、tr87(6)、vc33(7) | plan / engine 全通 |
| 有进度 | sc25(**4**)、wa30(**3**)、bp35(1)、su15(1) | plan 耗尽后续关未补 |
| 0 关 | cn04、dc22、g50t、ka59、lf52、m0r0、re86、s5i5、sk48、sp80、tu93 | unknown；本轮 IDDFS 曾因 `has_click` NameError 失效（已修） |

相对旧基线 35.38 / 7 WIN：`@800` 解锁 ls20/ar25 + **lp85 engine WIN** → **+7.4 / +3 WIN**。

说明：远程 engine_solver 缓存/源码布局若与本机不一致，**不能直接复现 lp85 全通**。提分仍以可回放 plan / 本机可复现路径为准。
