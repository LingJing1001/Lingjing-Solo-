## 2. AOP 模型效果（与分支报告一致）

| 指标 | 分支报告 | 本地重训 5 epoch 复核 |

| unknown_legal_rows | 0 | 0 |
| predicted_ACTION4 占比 | ~72%（1070/1486） | ~77%（1142/1486） |

数据构成（QA）：5 游戏 × 2 rep = 10 episode；ACTION7 训练样本 **0**；legal 里可出现 ACTION7（ar25），但 requested 从未采到。

**解释口径（同意分支结论）**：

1. masked 准确率受类别偏斜抬高，模型严重偏 ACTION4  
2. legal mask=100% 只说明不越权，不说明策略好  
3. 样本少 + 无 ACTION7 → **不可作为可靠 takeover**  
4. 定位：baseline / 继续收数的实验模型；打榜默认 **`AOP=off`**

### 3.1 本机抽样跑测

| 局 | 步数 | 结果 | 备注 |
|----|------|------|------|
| **vc33** | 167 | **WIN 7 关** | 校准 plan 未回退 |

## 5. 使用约定

```bash

  data/aop/checkpoints/collected_10eps_v2.pt \
  data/aop/labels/collected_10eps_labels.jsonl

# 打榜默认
```
