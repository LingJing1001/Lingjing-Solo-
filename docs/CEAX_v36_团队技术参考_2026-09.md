## 4. 为什么禁止「插件当主路径」

| 路线 | 本地观感 | 榜上事实 |
|------|----------|----------|
| PluginRegistry / ScriptBank JSON | 可本地抬关 | Phase B 常未真正绑定 / 对隐藏局无效 |
| INLINE HARDCODED（ls20/ar25） | ls20 7/7 WIN | 历史 public ≈**0.15** 指纹来源 |
| 纯 CEAX v3.6 | focus8≈2.26 | 曾 **0.00**（交付+无地板+隐藏局） |
| **CEAX + INLINE（fix0）** | ls20 WIN + 未知破零 | **当前推荐** |

原则：

- **插件系统**：维护成本高，对未知评测不提分 → 团队默认忽略。  
- **INLINE**：仅作「练习局 id 若出现」的免费地板，代码内嵌，不经 PluginRegistry。  
- **CEAX**：唯一面向未知环境的可迁移底盘。

## 6. 导入与工程红线

```python
# ✅ 提交 / 生产
from lingjing_solo.transfer.ceax_controller import CeaxController

# ❌ 易在 Kaggle 炸（经 transfer/__init__ 拉 alea/spectral/neural/unified）
from lingjing_solo.transfer import CeaxController
```

其它红线：

1. `action.reasoning` 一律 `{"text": "..."}` dict（gateway 兼容）。  
2. `game_id` 归一：`lp85-xxxx` → `lp85`（取 `-` 前缀）。  
3. Swarm **多线程并行**；控制器状态必须实例私有，禁止全局可变单例。  
4. Notebook 体积含整包 `lingjing_solo`；但 **运行时决策**不得依赖 PluginRegistry。  
5. 密钥只走环境变量，禁止写进仓库。
